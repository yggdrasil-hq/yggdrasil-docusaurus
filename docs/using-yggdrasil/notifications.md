# Notifications

The **Notifications** page is a global feed of events across all your projects — build completions, test failures, pull request merges, and other activity you should know about.

## What notifications cover

Examples of events that appear in the feed:

- Feature build completed or failed
- Test run completed or failed
- Pull request merged
- Project initialization complete
- Non-blocking messages from the agent during a run

Notifications are **informational** — they give you history and awareness even when you are not on a specific project page.

## Notifications vs. the action queue

These two surfaces work together but serve different purposes:

| Surface | Scope | Purpose |
|---------|-------|---------|
| **Action queue** | One project | Blocking work that needs your decision *now* |
| **Notifications** | All projects | Audit trail and awareness of what happened |

When something blocking appears in a project's action queue, Yggdrasil also emits a notification so you see it globally.

## In-app only (v1)

Notifications are shown inside the Yggdrasil web app. Email and push notifications are not available in the current version.

Use **Mark all read** to clear unread items when you have caught up.
