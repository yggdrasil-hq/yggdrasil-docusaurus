# Brand Assets

Official Yggdrasil logos for press, partnerships, and integrations. All assets are provided in SVG (vector) and PNG (raster) formats.

**Usage guidelines:** Do not recolor, stretch, or modify the logos. Use the variant that provides sufficient contrast against your background.
